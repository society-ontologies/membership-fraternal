Description

Επέκταση της Οντολογίας οργανώσεων μελών (membership) για αδελφικά τάγματα, στοές, αδελφότητες φοιτητών και αδελφότητες γυναικών: συστήματα βαθμών και η σειρά τους, μύηση και απονομή βαθμών, στοές και ανώτατα όργανα, τελετές, διάσημα, αναγνώριση και φιλία μεταξύ ταγμάτων, και αξιολογήσεις για το αν ένα ιπποτικό τάγμα είναι γνήσιο.

Description

Βαθμός c

IRI https://w3id.org/fraternal#Degree
Is Defined By Οντολογία αδελφικών ταγμάτων και αδελφοτήτων γυναικών
Description

Ένας βαθμός ή βαθμίδα μέσα σε ένα σύστημα βαθμών. Ένας βαθμός της αριθμημένης ακολουθίας έχει τη θέση του δοσμένη από τα fraternal:degreeRank και fraternal:nextDegree — όχι από το skos:broader, που θα υποστήριζε ότι ένας ανώτερος βαθμός είναι στενότερη έννοια ενός κατώτερου. Οι τιμητικοί βαθμοί, οι βαθμοί αξιώματος και οι πλευρικοί βαθμοί που βρίσκονται εκτός της ακολουθίας δεν έχουν σειρά· το είδος τους δίνεται με το fraternal:degreeKind.
Scope Note

Ο αριθμός ή η συντομογραφία που χρησιμοποιεί το ίδιο το τάγμα για έναν βαθμό (π.χ. IV–V, 3=8, RKFV) μπαίνει στο skos:notation. Μπορεί να διαφέρει από τη σειρά ή να είναι αντίστροφος.

Αναγνώριση c

IRI https://w3id.org/fraternal#Recognition
Is Defined By Οντολογία αδελφικών ταγμάτων και αδελφοτήτων γυναικών
Description

Η επίσημη αναγνώριση ενός σώματος από ένα άλλο για μια περίοδο: μια μεγάλη στοά που αναγνωρίζει μια άλλη ως κανονική, δύο τάγματα σε φιλία, δύο σώματα που επιτρέπουν στα μέλη του άλλου να τα επισκέπτονται. Δίνει το σώμα που αναγνωρίζει (fraternal:recognizingBody), το σώμα που αναγνωρίζεται (fraternal:recognizedBody), το είδος (fraternal:recognitionType), και πότε άρχισε και, αν έληξε, πότε (mbr:startDate, mbr:endDate).
Scope Note

Τα fraternal:recognizes και fraternal:inAmityWith δηλώνουν το παρόν σε μία τριπλέτα και παραμένουν γι' αυτό. Η αναγνώριση χρησιμοποιείται όταν μετράνε οι ημερομηνίες ή το τέλος της σχέσης. Η αναγνώριση έχει κατεύθυνση: αν τα δύο σώματα αναγνωρίζουν το ένα το άλλο, δίνονται δύο αναγνωρίσεις· η φιλία είναι αμοιβαία και δίνεται μία φορά. Μια αναγνώριση που ανακλήθηκε έχει ημερομηνία λήξης. Το αν το άλλο σώμα κρίθηκε κανονικό, μη κανονικό ή κρυφό (clandestine) είναι fraternal:LegitimacyAssessment.

Αξιολόγηση νομιμότητας c

IRI https://w3id.org/fraternal#LegitimacyAssessment
Is Defined By Οντολογία αδελφικών ταγμάτων και αδελφοτήτων γυναικών
Description

Μια δήλωση ενός παράγοντα — μιας επιτροπής όπως η ICOC, της Αγίας Έδρας, ενός κράτους ή ενός άλλου τάγματος — για το αν ένα τάγμα είναι γνήσιο ιπποτικό τάγμα ή μπορεί να φέρεται, με το αποτέλεσμά της (fraternal:assessmentOutcome), την ημερομηνία (mbr:startDate) και την πηγή (dcterms:source).
Scope Note

Χρησιμοποιείται και για την κανονικότητα ενός τεκτονικού σώματος, όπως κρίνεται από άλλο ανώτατο όργανο: το αποτέλεσμα είναι τότε fraternalc:regular, fraternalc:irregular ή fraternalc:clandestine. Η αναγνώριση που ακολουθεί είναι fraternal:Recognition.
