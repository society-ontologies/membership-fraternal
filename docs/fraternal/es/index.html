Description

Extensión de la Ontología de organizaciones de miembros (membership) para órdenes fraternales, logias, fraternidades y sororidades: sistemas de grados y su orden, iniciación y concesión de grados, logias y organismos rectores, ceremonias, insignias, reconocimiento y amistad entre órdenes, y evaluaciones de si una orden de caballería es auténtica.

Classes

Orden fraternal c

IRI https://w3id.org/fraternal#FraternalOrder
Is Defined By Ontología de órdenes fraternales y sororidades
Description

Una organización de miembros cuyos integrantes son admitidos por iniciación y avanzan a través de un sistema de grados, normalmente bajo juramento y con ritual. Abarca fraternidades, sororidades, órdenes mixtas y de adopción. El tipo de orden se indica con org:classification (véase fraternalc:OrderTypes).
Scope Note

Se usa también para las órdenes de caballería, auténticas o autoproclamadas, descritas como organizaciones de sus miembros (fraternalc:orderOfChivalry, fraternalc:selfStyledOrderOfChivalry). En sueco son riddarordnar, no ordenssällskap. Una orden de mérito que consiste solo en una dignidad y sus insignias es una mbr:Distinction, no una organización.
Sub Class Of https://w3id.org/membership#MembershipOrganization

Grado c

IRI https://w3id.org/fraternal#Degree
Is Defined By Ontología de órdenes fraternales y sororidades
Description

Un grado o escalón dentro de un sistema de grados. Un grado de la secuencia numerada tiene su posición indicada por fraternal:degreeRank y fraternal:nextDegree —no por skos:broader, que afirmaría que un grado superior es un concepto más específico de uno inferior—. Los grados honoríficos, de cargo y laterales que quedan fuera de la secuencia no tienen rango; su tipo se indica con fraternal:degreeKind.
Scope Note

El numeral o la abreviatura propios de la orden para un grado (p. ej., IV–V, 3=8, RKFV) van en skos:notation. Puede diferir del rango o ir en sentido inverso.

Reconocimiento c

IRI https://w3id.org/fraternal#Recognition
Is Defined By Ontología de órdenes fraternales y sororidades
Description

El reconocimiento formal de un organismo por otro durante un período: una gran logia que reconoce a otra como regular, dos órdenes en amistad, dos organismos que permiten visitar sus reuniones a los miembros del otro. Indica el organismo que reconoce (fraternal:recognizingBody), el organismo reconocido (fraternal:recognizedBody), el tipo (fraternal:recognitionType), y cuándo empezó y, si terminó, cuándo (mbr:startDate, mbr:endDate).
Scope Note

fraternal:recognizes y fraternal:inAmityWith expresan el presente en un solo triple y se mantienen para eso. Se usa un reconocimiento cuando importan las fechas o el fin de la relación. El reconocimiento tiene dirección: si ambos organismos se reconocen entre sí, se dan dos reconocimientos; la amistad es mutua y se da una sola vez. Un reconocimiento retirado tiene fecha de fin. Que el otro organismo haya sido considerado regular, irregular o clandestino es una fraternal:LegitimacyAssessment.
Sub Class Of Activity c
In Domain Of
  • organismo que reconoce op
  • organismo reconocido op
  • tipo de reconocimiento op

Evaluación de legitimidad c

IRI https://w3id.org/fraternal#LegitimacyAssessment
Is Defined By Ontología de órdenes fraternales y sororidades
Description

Una declaración de un agente —una comisión como el ICOC, la Santa Sede, un Estado u otra orden— sobre si una orden es una auténtica orden de caballería o puede llevarse, con su resultado (fraternal:assessmentOutcome), fecha (mbr:startDate) y fuente (dcterms:source).
Scope Note

Se usa también para la regularidad de un organismo masónico, juzgada por otro organismo rector: el resultado es entonces fraternalc:regular, fraternalc:irregular o fraternalc:clandestine. El reconocimiento que sigue es un fraternal:Recognition.
Sub Class Of Activity c
